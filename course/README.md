# Material do curso

Esta pasta contém o material que pode ser estudado independentemente da interface do Campus.

## Exercícios JavaScript

[`exercicios-javascript/`](./exercicios-javascript/) reúne 69 arquivos `.js`, organizados do M01 ao M12 na mesma sequência pedagógica apresentada pelo portal.

Cada módulo mantém aulas, exercícios e desafios próximos entre si para facilitar prática direta, revisão e consulta.

# Product Spec · Campus Backend — Preparatório para o SENAI

## Missão

Oferecer a Carlos Pereira um curso preparatório independente para fortalecer sua base antes e durante o aprofundamento no SENAI. O campus também deve servir como trilha aberta para outras pessoas que queiram aprender JavaScript com foco em Backend. A experiência deve permitir que o aluno responda três perguntas em qualquer tela: **onde estou, o que já aprendi e qual é o próximo passo**.

O projeto não representa, não substitui e não afirma ser material oficial do SENAI.

## Linguagem e formação

- Linguagem pedagógica principal: JavaScript.
- Direção profissional: Backend com Node.js.
- Fundamentos estudados permanecem no histórico como conhecimento lógico reaproveitável.

## Princípios de experiência

1. Navegação por áreas e abas, não uma página infinita única.
2. Aulas antigas têm o mesmo padrão pedagógico da aula atual.
3. Código vem depois do modelo mental.
4. Exercícios possuem numeração consistente e arquivos `.js`.
5. Comentários `//` explicam a intenção sem transformar cada linha em ruído.
6. O aluno pode limpar marcações de revisão sem apagar progresso acadêmico.
7. Gamificação recompensa compreensão e prática, não apenas cliques.
8. Um módulo só muda para concluído quando sua evidência de domínio é satisfeita; no M07, essa evidência é a missão funcional 4/4.

## Estrutura pedagógica de uma aula

- objetivo;
- pré-requisitos;
- história do programa;
- execução passo a passo;
- conceitos centrais;
- código comentado;
- leitura mental;
- erros comuns;
- checkpoint.

## Laboratório atual e evolução

Atual: Monaco → Web Worker local com timeout → captura de console → casos de teste específicos da missão → feedback estruturado.

Produção futura: frontend Monaco → API de submissão → fila → worker Node.js isolado → testes por exercício → resultado estruturado → feedback pedagógico.

Não executar código arbitrário no servidor principal.

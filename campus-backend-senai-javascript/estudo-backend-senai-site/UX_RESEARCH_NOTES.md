# UX / Learning Notes · JavaScript Track

A evolução 6.0 mantém o campus com estética acadêmica e aumenta a densidade pedagógica em vez de reduzir o conteúdo a cards superficiais.

## O que o aluno deve enxergar

- identidade clara: JavaScript Backend;
- progresso real e conteúdo já estudado;
- aula atual dentro do módulo selecionado;
- biblioteca permanente de revisão;
- códigos legíveis e comentados;
- sequência futura até Backend Node.js;
- separação explícita entre lógica universal e particularidades do JavaScript.

## Referências conceituais usadas na trilha

A ordem de fundamentos segue a progressão natural documentada no JavaScript Guide: sintaxe e tipos, controle de fluxo, laços, funções, coleções/arrays, objetos, promises e módulos. Para Backend, a trilha acrescenta Node.js e depois HTTP/Express.

## Critério de não-genericidade

Evitar estética de "dashboard SaaS" sem contexto. O design deve comunicar formação, biblioteca, aula, laboratório e progresso acadêmico. A identidade JavaScript aparece como selo editorial, sem transformar toda a interface em amarelo/preto.
